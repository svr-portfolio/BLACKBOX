# BLACKBOX – Accident Reconstruction Engine

## About BLACKBOX

BLACKBOX is a Java-based Accident Reconstruction Engine developed as a course project.

The main idea behind BLACKBOX is to organize accident-related information such as vehicles, evidence, events, and other available details in one place and use that information for accident reconstruction and analysis.

The project is being developed with a focus on applying Java programming concepts to a practical problem.

## Technologies Used

- Java
- NetBeans IDE
- Apache Ant
- Git and GitHub

## Requirements

Before running BLACKBOX, make sure the following are available on your system:

- Java Development Kit (JDK)
- NetBeans IDE
- Apache Ant
- Git (for cloning or working with the repository)
